# D365 Script Devtool Privacy Policy

**Last updated: August 24, 2026**

D365 Script Devtool is a Chrome extension for Microsoft Dynamics 365 and Microsoft Dataverse. It helps developers create, edit, publish, and associate web resources and form event handlers directly from Dynamics 365 forms.

## Data Access

When the extension is used, it may access information from the user's Microsoft Dynamics 365 or Microsoft Dataverse environment that is necessary to provide the extension's functionality.

This may include:

* Dataverse web resource names and content
* JavaScript web resource content
* Form configuration and metadata
* Form event handlers
* Form fields and related metadata
* Other Dataverse metadata required to perform actions requested by the user

## How Data Is Used

The information accessed by D365 Script Devtool is used solely to provide the extension's functionality.

For example, the extension may read, create, update, or publish web resources and may create, modify, or remove form event handlers when requested by the user.

The extension operates in the user's browser and interacts with the user's Dynamics 365/Dataverse environment using the user's existing authenticated session.

## Data Collection and Storage

D365 Script Devtool does not operate a developer-owned backend server for collecting or storing Dynamics 365/Dataverse data.

The extension does not intentionally transmit Dynamics 365/Dataverse data to servers operated by the developer.

The extension does not collect or store users' Dynamics 365 passwords or authentication credentials.

## Data Sharing

D365 Script Devtool does not sell user data.

D365 Script Devtool does not share Dynamics 365/Dataverse information with third parties for advertising, marketing, profiling, or unrelated purposes.

## Analytics and Tracking

D365 Script Devtool does not use advertising, analytics, or tracking services to monitor users' activity.

## Data Security

The extension relies on the user's existing authentication and authorization within Microsoft Dynamics 365/Dataverse.

Users should only use the extension in environments where they have appropriate authorization to perform the requested customizations.

## Changes to This Privacy Policy

This privacy policy may be updated if the extension's functionality or data practices change. The latest version will be published in this repository.

## Contact

For questions, privacy concerns, or issues relating to D365 Script Devtool, please open an issue in the project's GitHub repository.

---

This privacy policy applies to the D365 Script Devtool Chrome extension.
